Питання

Що зазвичай питають

Скільки це коштує?

Зараз безкоштовно: ми збираємо першу групу й хочемо чесного фідбеку.

Хто пише рев'ю?

Людина, за детальною рубрикою кейсу: що мав знайти сильний кандидат, типові помилки й що робити далі.

Дані справжні?

Ні, вони синтетичні: згенеровані скриптом із закладеною проблемою, як у реальному продукті. Тому розв'язків у мережі немає, а правильність висновку можна перевірити.

Можна показувати роботу роботодавцю?

Так, це твоя робота. У README чесно пишеш, що дані синтетичні, а кейс змодельований під реальну ситуацію. Шаблон README приходить разом із рев'ю.

Скільки часу це займає?

Кейс розрахований на 2–4 години роботи. Дедлайн 2–3 дні, щоб вмістити його між парами.
