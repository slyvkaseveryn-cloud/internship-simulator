### Про продукт
Той самий застосунок для вивчення англійської. Користувач бачить пейвол із пропозицією Pro і може одразу купити місячну підписку. Покупку можна повернути (рефанд) протягом кількох днів.

### Дані

**users.csv**: один рядок на користувача, якого призначили в тест.

| колонка | опис |
|---|---|
| user_id | ідентифікатор |
| assigned_ts | час призначення в групу, UTC |
| group | A (199 грн) або B (249 грн) |
| platform | ios / android |
| country | країна |
| is_returning | 1, якщо користувач уже бачив пейвол до початку тесту |

**events.csv**: події на пейволі.

| колонка | опис |
|---|---|
| event_id | ідентифікатор події |
| user_id | ідентифікатор користувача |
| event_name | paywall_view, purchase, refund |
| event_ts | час події, UTC |
| amount_uah | сума: додатна для purchase, від'ємна для refund |

**day3_report.md**: проміжний звіт Максима за перші три дні.
