### Про продукт
Мобільний застосунок для вивчення англійської (iOS і Android). Після онбордингу користувач отримує 7-денний безкоштовний тріал, потім оформлює підписку: місячну (199 грн) або річну (1490 грн).

### Дані

**users.csv**: один рядок на користувача.

| колонка | опис |
|---|---|
| user_id | ідентифікатор |
| signup_ts | час встановлення, UTC |
| platform | ios / android |
| app_version | версія застосунку при встановленні |
| channel | джерело трафіку |
| country | країна |

**events.csv**: події з застосунку.

| колонка | опис |
|---|---|
| event_id | ідентифікатор події |
| user_id | ідентифікатор користувача |
| event_name | install, onboarding_complete, trial_start, paywall_view, purchase_click, purchase_success |
| event_ts | час події, UTC |
| amount_uah | сума оплати (лише для purchase_success) |
